# 适用现象

视觉控制器可能出现相机掉线、图像延迟、重复误检、存储告警或机箱温度升高。先保存告警时间、软件版本和最近配置变更，避免在没有备份时恢复出厂设置。

# 建议检查

确认控制器供电稳定，网线与相机连接器锁紧，交换机端口没有大量丢包。检查镜头污染、光源亮度、曝光和触发时序是否变化。清理进风口并确认风扇运行，但不要在带电状态下伸入机箱。磁盘空间不足或时间同步异常也可能造成日志和图像处理问题。

# 处置

先区分单个相机故障、网络故障与控制器整体故障。恢复已验证的配置前应导出当前配置。若控制器反复重启、闻到焦味或电源异常，应断电并交由合格人员检修。

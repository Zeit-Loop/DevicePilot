# 适用现象

离心泵出现尖锐噪声、流量波动、壳体振动或轴承温度升高时，应先降低负载并确认是否存在泄漏、异常压力或旋转部件风险。发现大量泄漏、冒烟或剧烈振动时应停机隔离能源。

# 建议检查

确认入口阀完全开启，入口滤网没有堵塞，液位和吸入压力满足要求。汽蚀通常伴随类似碎石撞击的噪声，常见原因包括入口受阻、液位过低、介质温度过高或吸入管漏气。检查联轴器对中、底座紧固、叶轮异物和轴承润滑状态；不要在设备运行时拆卸防护罩或触碰旋转部件。

# 处置

记录入口与出口压力、振动位置和温度趋势。修正入口条件后仍有异常噪声或振动，应保持停机并由合格人员检查叶轮、机械密封、联轴器和轴承。
